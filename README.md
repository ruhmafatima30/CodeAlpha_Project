# 🌐 AI Language Translation Tool

A web-based **AI Language Translation Tool** developed as part of my **CodeAlpha AI Internship**. The application provides a simple and user-friendly interface for translating text between different languages.

The project is built using **Python, Flask, HTML, CSS, and JavaScript**, with a translation service used to process the entered text.

## ✨ Features

* 🌍 Translate text between multiple languages
* 🔄 Select source and target languages
* 📝 Simple text input interface
* ⚡ Fast translation processing
* 📋 Easy-to-read translated output
* 📱 Responsive and user-friendly interface
* 🎨 Clean and modern web design
* 🧹 Clear input/output functionality
* 📋 Copy translated text easily

## 🛠️ Technologies Used

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/ruhmafatima30/CodeAlpha_Project.git
```

### 2. Open the Project Folder

```bash
cd CodeAlpha_Project
cd "AI-Translation tool"
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows PowerShell:**

```powershell
.\venv\Scripts\Activate.ps1
```

If PowerShell blocks script execution, run:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Then activate again:

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install Dependencies

```bash
pip install flask
```

If your project contains a `requirements.txt` file, use:

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

### 7. Open in Browser

After starting the Flask server, open the local address shown in the terminal, for example:

```text
http://127.0.0.1:8000
```

or

```text
http://127.0.0.1:5000
```

## 💡 How It Works

1. Enter the text you want to translate.
2. Select the **source language**.
3. Select the **target language**.
4. Click the **Translate** button.
5. The application sends the text for translation.
6. The translated result is displayed on the screen.
7. The user can copy the translated text.
