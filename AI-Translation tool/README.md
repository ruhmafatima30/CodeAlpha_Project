# CodeAlpha Language Translation Tool

A modern and user-friendly web-based Language Translation Tool developed as part of the CodeAlpha Internship Program.

## ✨ Features

- 🌍 Translate text between multiple languages
- 🔄 Swap source and target languages
- 📋 Copy translated text
- 🔊 Listen to translated text using text-to-speech
- 📝 Character counter
- ⚡ Fast translation
- ⏳ Loading indicator during translation
- ❌ Error handling for failed translations
- 📱 Responsive design for different screen sizes
- 🎨 Modern and professional user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Python
- Flask
- Requests
- MyMemory Translation API
